# v1.0.17

- 重构为 iOS 18 风格的磨砂界面：柔和底色、不透明分组卡片、圆角控件和轻阴影，支持系统深浅色。
- 代理规则以桌面双列、手机单列卡片展示，突出名称、来源 → 目标、端口和运行状态。
- 每张规则卡片直接提供开启 / 关闭开关。沿用真实启停接口，处理中禁用重复操作，保留失败提示及状态同步。
- 搜索、协议筛选、批量操作、运行详情、编辑和菜单操作继续可用；移动端六个导航入口保持直接可见。
- 优化窄屏长端口范围、规则名称和目标地址换行，固定开关尺寸，保留安全区域空间。
- 快捷启停失败原因保留在对应卡片中；断网时明确提示结果待确认，重试成功后清除。手机导航使用短标签，增大地址及连接信息字号。

本次仅修改前端布局与样式；代理、证书签发、DDNS 和系统 HTTPS 部署行为不变。
